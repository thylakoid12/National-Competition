第二问建模正文示例

这份示例对应本次统计预测与风险决策模型。正文按照决策发生的顺序展开，公式编号暂用“示例1”等标记，排入论文时再与全文统一。后面的消融和压力结果分析可以接在本节之后。

决策与信息统计预测误差场景计划执行优化目标求解与更新风险与选型

5.2 考虑预测误差的购电与储能决策

问题二需要在负载和光伏尚未确定时制定购电计划。如果只按照一条预测曲线安排购电，一旦实际负载偏高或光伏出力偏低，原计划就可能留下供电缺口，需要以五倍电价紧急补购。提前多买一些电能够缓解这一风险，但多买的电未必都能用完，储能设备也无法无限吸收余电。因此，本问需要同时考虑购电费用和预测失误带来的损失。

为此，本文先利用历史数据预测当天供需，再根据过去的预测误差构造多种可能的运行情况。对每一份候选购电计划，均用同一套储能控制规则模拟其在各场景中的运行，计算正常购电费、紧急购电费和日末库存。在此基础上调整购电量与留电策略，得到当天的日前计划。计划确定后，日内仅根据已经观测到的供需状况执行充放电和紧急补购。

5.2.1 决策时刻与可用信息

沿用问题一的十分钟时间尺度，将一天分为144个时段。记第 d 日第 t 个时段的负载、光伏发电量、日前计划购电量和紧急购电量分别为 Ld,t、Vd,t、Gd,t 和 Hd,t，单位均为kWh。记 Ed,t 为第 t 个时段结束后的储电量，其中 Ed,0 表示当天日初库存。

每天0:00制定计划时，可以使用此前各日的负载、光伏、预测误差和上一日的实际日末库存，当天尚未发生的实测值不参与决策。当天144个时段的计划购电量一经确定便保持不变，日内出现偏差时，由储能和紧急购电共同调节。当天运行结束后，再将实际库存和新产生的预测误差带入次日。连续运行期间有

Ed+1,0 = Ed,144。（示例1）

这里不再要求每天结束时回到当天的初始库存。题目给定的6000 kWh用于1月1日的启动状态；正式评价从共同预热得到的库存出发，此后各模型沿用自身的实际日末状态。这样可以反映当天的留电或放电对后续运行的影响。

记正常电价为 pt，当天实际支付的费用为

Jcashd = ∑t=1144 ptGd,t + 5∑t=1144 ptHd,t。（示例2）

日前购电按计划量计费，即使用不完也不能退还。因此，模型既要避免购电不足造成高价补购，也要避免过度采购。

5.2.2 用统计规则得到供需预测

预测的作用是给出当天供需的大致水平。考虑到模型需要便于解释，本文采用历史均值、同星期均值和局部线性外推等统计规则作为候选方法，分别预测负载与光伏。以1月2日至31日的30天为规则比较期，每一天的预测都只使用此前已经观测到的数据，再用当天的实测值计算误差。

表6给出各基础规则的平均绝对误差。负载采用最近三个同星期日均值时，一月MAE最低，为288.054 kW；光伏采用最近七日均值时最低，为87.048 kW。因此，二月起固定采用这两个基础规则。固定的是计算方法，参与计算的历史日期仍随目标日向前移动。历史窗口完整时，基础预测写为

L̃d,t = (Ld−7,t + Ld−14,t + Ld−21,t) / 3，Ṽd,t = (1/7)∑j=17Vd−j,t。（示例3）

在历史不足时，负载规则对已有的同星期日取均值；若还没有同星期参考日，则使用此前全部可用日期的同一时段均值。光伏不足七日时，按实际已有天数取均值。一月运行期间，基础规则的选择依据此前已经结算的累计误差更新，二月起不再重新选型。

历史均值能够反映一般规律，但近期负载水平和光伏出力仍可能发生偏移。为利用这种变化，本文在基础预测上增加一个幅度受限的偏差修正。以负载或光伏中的任一对象 X 为例，记其基础预测为 X̃d,t，最终发布的预测为 X̂d,t，则

X̂d,t = [X̃d,t + clip(0.25 ēbased,t, −cd,t, cd,t)]+。（示例4）

其中，ēbased,t 是最近七个已结算日同一时段的基础预测误差均值，误差按“实测值减去当时的基础预测”计算；不足七日时使用已有误差。修正上限 cd,t 取基础预测与近七日实测均值中较大者的25%。clip表示将修正量限制在给定上下界内，[·]+表示取非负部分。若近期经常低估某一时段，预测会适当上调；限幅则避免少数异常日把下一日预测拉得过远。对过去30天光伏始终为零的时段，预测仍设为零。

表6比较的是未加修正的基础规则，修正效果应另用同一时期的修正前后误差评价。M0—M3使用相同的最终预测，因此后续消融实验比较的是不确定性利用方式和决策机制的差异。

5.2.3 用历史误差描述可能的供需变化

一条预测曲线无法说明预测可能偏离多少。为此，本文保留历史上每天实际发生的预测误差，并把它们作为当天供需变化的参考。记 Yi 为第 i 日负载与光伏组成的整日向量，包含两个对象各144个时段的电量；Ŷi|i−1 为当天日初实际发布的修正后预测，则该日联合误差为

εi = Yi − Ŷi|i−1。（示例5）

对第 d 日，从此前最多60个有效误差日中取出 nd 条联合误差，将其分别加到当天预测上，得到

Y(i)d = [Ŷd|d−1 + εi]+，i < d。（示例6）

这样构造的场景可以理解为：如果过去某一天的预测偏差在今天再次出现，今天的供需曲线可能是什么样。负载和光伏的误差按整日共同保留，不对各时段独立打乱，从而保留连续偏高、连续偏低以及两者同时变化的历史特征。光伏场景也采用仅由过去数据确定的夜间零值掩码。

不同历史日与今天的条件并不完全相同。本文根据星期类别、前一日以及近七日的负载与光伏总量等已知信息计算场景距离，给较相近的历史日更高权重。记标准化后的特征距离为 Dd,i，场景权重取为

wd,i = 0.75 · exp[−Dd,i/(2h2)] / ∑jexp[−Dd,j/(2h2)] + 0.25/nd，h = 1。（示例7）

距离的标准化尺度仅由已有历史估计。式中保留25%的均匀权重，使较不相似的历史日仍有一定影响，避免在样本不多时过度依赖少数场景。至此，模型得到当天的供需预测、若干种可能偏差，以及每种情况在决策中所占的比重。

5.2.4 一份购电计划怎样执行

有了场景，还需要回答：如果采用某份购电计划，电池会怎样运行，又会发生多少紧急购电？本文用一套固定的反馈规则回答这个问题。对所有模型和场景使用相同规则，避免把控制方式的变化混入消融结果。

对于候选计划 Gd，先在当天点预测路径上求解参考调度线性规划。该规划在给定计划购电量下，考虑紧急费用与日末余电价值，得到参考库存轨迹 Rrawd,t。在参考规划的最优费用容差内，再选择总库存较高的轨迹。随后用一个系数 αd 调整留电程度：

Rd,t = Emin + αd(Rrawd,t − Emin)，0 ≤ αd ≤ 1。（示例8）

α=1时采用原参考轨迹，α=0时将放电保留阈值降到库存下界。α与144个时段的购电量一起优化，并在日初锁定。参考库存只限制缺电时可以释放多少电量，并不要求实际库存始终达到这条线，也不会因为库存低于参考线就额外买电强行充满。

进入第 t 个时段后，控制器读取当前负载、光伏和库存。记计划购电与光伏扣除负载后的余额为 ad,t=Gd,t+Vd,t−Ld,t，每时段充放电上限为 B=5000/6 kWh，则充电量 Cd,t、放电量 Dd,t 与紧急购电量按下式确定：

Cd,t = min{[ad,t]+, B, (Emax−Ed,t−1)/ηc}， Dd,t = min{[−ad,t]+, B, ηd[Ed,t−1−Rd,t]+}， Hd,t = [−ad,t]+ − Dd,t。（示例9）

供电富余时，在功率和容量允许的范围内充电；供电不足时，先释放参考库存以上可用的电量，再通过紧急购电补齐缺口。例如，某时段负载100 kWh、光伏20 kWh、计划购电50 kWh，仍有30 kWh缺口。若电池按上述规则只能向负载释放10 kWh，则需要紧急补购20 kWh。这个例子也说明，电池还有余电时仍可能发生紧急购电，因为部分余电可能被保留给后面的时段。

库存按实际充放电量递推：

Ed,t = Ed,t−1 + ηcCd,t − Dd,t/ηd，ηc=ηd=0.9。（示例10）

库存范围为1200—10800 kWh。富余电量中无法存入电池的部分，先在计划购电量范围内记为未使用计划量 Ud,t，其余记为弃光 Wd,t，即 Ud,t=min{Gd,t,[ad,t]+−Cd,t}，Wd,t=[ad,t]+−Cd,t−Ud,t。这两项均不抵扣已支付的计划购电费。

给定一份计划和参考线后，在每条假设场景中依次执行上述规则，就能得到该场景的紧急购电与日末库存。真实运行采用同样的规则，但每次只读取已经发生的时段；场景模拟可以遍历一整天，并不意味着实际控制提前知道了未来。

5.2.5 根据场景费用选择购电计划

记候选计划在场景 i 下产生的紧急购电费为 Kd,i。如果只比较当天费用，优化器可能倾向于把电池用到接近下界，却不考虑留给下一天的电量。为了兼顾下一天仍可使用的电量，本文在比较计划时给日末余电一个估值：

Kd,i = 5∑t=1144ptH(i)d,t，Qd,i = Kd,i − νd(E(i)d,144−Emin)。（示例11）

通常取 νd=mint(pt)/ηc，12月31日因评价期结束取零。Qd,i是比较计划时的评分，日末余电并未实际出售；论文中的真实购电费用仍按式（示例2）计算，不能把库存估值当成现金收入。

历史场景权重只是对未来概率的估计。如果实际情况比这些权重暗示的更不利，按名义平均费用制定的计划仍可能过于乐观。为此，M3允许各场景概率在名义权重附近小幅变化，并按照其中最不利的费用评价计划。所用概率集合为

𝒫d(ρ) = {q : qi ≥ 0，∑iqi = 1，½∑i|qi−wd,i| ≤ ρ}，ρ = 0.05。（示例12）

ρ=0.05表示最多重新分配5%的概率质量，不表示负载或光伏只能波动5%。在这一集合内，费用较高的场景可以获得更多权重，从而增加其对日前决策的影响。M3的优化目标为

minGd≥0, 0≤αd≤1 {∑t=1144ptGd,t + maxq∈𝒫d(ρ)∑iqiQd,i(Gd,αd)}。（示例13）

这里的紧急购电和库存由前述控制规则产生，不能在每个场景中任意选择一套事后最优动作。购电计划的优劣，取决于同一套可执行规则面对不同供需路径时的实际表现。

为检验各部分的作用，本文保留共同预测器、控制器和决策自由度，只改变场景及其权重处理方式，构成M0—M3的递进消融：

模型场景与权重用于比较的作用
M0仅使用当天点预测路径不利用历史误差时的基准
M1使用历史误差场景，各场景等权检验纳入预测误差的作用
M2使用相同场景，按条件赋予权重检验区分历史日参考价值的作用
M3在M2权重附近考虑TV概率变化检验对概率估计偏差保持谨慎的作用

因此，M0—M3并不是四套不同的预测算法。它们的差别在于：拿到相同的统计预测后，如何利用历史误差，以及如何评价不利运行情况。

5.2.6 计划求解与逐日更新

上述目标需要经过储能控制规则的逐时模拟才能求值，其中包含充放电切换和上下界截断，难以直接作为一个普通线性规划求解。本文采用多起点局部搜索。先由确定性调度与预测净负荷等方案构造三个起点，再依次调整连续两小时、一小时和十分钟范围内的购电量，同时调整α，并尝试在不同时段之间转移购电量。每次改动后，都重新计算参考线并评价场景费用。候选之间先比较可行性，再比较目标值；对于尚未满足风险限额的扩展候选，优先减小约束违反程度。

每个模型每天最多进行3000次候选评价，使消融模型获得相同的搜索预算。对固定候选计划，M3的最坏场景期望通过将概率质量从低评分场景移向高评分场景计算。搜索结束后，保存选定的购电计划、α和参考线，并按前述规则进行当天的真实运行。由于外层采用有限预算局部搜索，所得结果是当前搜索范围内的较优方案，不将其称为已经证明的全局最优解。

日末更新包括两部分：一是将实测值与当日日初预测比较，把新的误差加入历史库；二是将实际日末库存带入下一天。这样，近期偏差、场景组成和当前库存都能影响下一份计划。基础预测规则和主要参数在评价期间保持不变，因此这种更新体现的是对新信息的滚动适应，其效果仍需由预测误差和实际费用检验。

5.2.7 风险评价、模型选型与压力检验

平均费用较低，并不代表高损失日的表现也好。本文在计划确定后，使用共同的历史条件场景计算紧急购电费用的VaR和CVaR，为当天计划提供事前风险报告。设场景紧急费用为 Kd,i，权重为 wd,i，置信水平取β=0.9，则

CVaRβ(Kd) = minτ{τ + [1/(1−β)]∑iwd,i[Kd,i−τ]+}。（示例14）

CVaR关注费用分布最差10%概率质量对应的平均费用，能够补充平均费用对尾部损失的描述。它不是单日费用上界。正式评价结束后，再用334天真实日紧急费用计算经验CVaR，检验已经发生的尾部损失；两类CVaR分别用于事前提示和事后评价，不混用样本。

模型选择在一月完成。1月1日从6000 kWh启动，因没有此前数据，采用零日前计划并对剩余缺口紧急补购；1月2日起用因果统计预测和确定性调度方案进行共同预热。候选模型在1月15日至31日比较，从1月14日共同预热的日末库存开始运行。首先要求验证期总现金费用不超过M2的1.03倍，再比较真实紧急费用CVaR和开发压力费用CVaR。将这两项风险分别除以M2的对应值，取较大的比值作为选型指标，较小者优先；若并列，再比较总费用。

开发压力采用负载增加10%、光伏减少30%及两者同时发生三种情况。对每个验证日，保持计划不变，在实测曲线上施加上述冲击，先取三种情况下的最大紧急费用，再在验证日之间计算其CVaR。额外设置的CVaR限额和设计压力保护候选还需满足各自约束。其中，设计压力约束在日初预测曲线上检查；这里用于验证评分的开发压力则在日末实测曲线上回放，两者不混用。本次按上述规则选定M3后，将模型冻结，用二月至十二月的334天检验后续表现。正式评价从1月31日共同预热得到的10800 kWh开始，各模型此后连续衔接自身库存。

3%的要求是验证期模型筛选条件，后续费用是否仍满足这一增幅需要单独核验。最终M3使用TV鲁棒目标，CVaR用于风险报告和选型，并未启用扩展候选中的CVaR或压力硬约束。

考虑到历史误差不一定包含更强的冲击，本文另设不参与选型的压力测试：在四季代表日施加更大幅度的负载增加、光伏下降、晚峰增加以及多日联合冲击，并增加低初始库存的情形。受压与配对正常运行的首日执行同一份已经锁定的计划，次日起只能利用已观测到的受压历史重新决策。比较紧急购电量、额外现金费用及库存轨迹，可以观察模型在哪些条件下仍有缓冲能力，在哪些条件下容易退化。

上述检验基于历史数据回放及人工压力情景。由于当前允许用紧急购电补齐负载缺口，本文所讨论的抗压表现主要是费用与应急依赖方面的表现，并不等同于电网限供或停电条件下的供电可靠性。后续的消融与压力分析据此同时报告改善和退化，而不把单一指标的下降解释为所有风险均得到控制。
