# 本次实验的论文与核验资料

本目录在原运行电脑上保存完整实验，在 Git 仓库中提供精简资料。仓库包含冻结配置与选型、七个模型的验证和评价汇总、逐日指标 CSV、压力测试汇总、核验记录，以及 HTML 分析使用的四个指定日明细。模型计算结果未因整理或上传而重新运行。

完整的逐日搜索日志、锁定计划、全年数组、预测缓存和压力过程仍保存在原电脑的同名目录，未随 Git 上传。它们不是已删除的数据；新 clone 得到的精简资料也不构成可直接续跑的完整检查点。

## 阅读与重绘

- [论文入口](../../../论文用结果/00_从这里开始.html)：建模正文示例、消融实验、风险分析与压力测试。
- [图表资料包](../../../论文用结果/正文图.zip)：包含正文图片及 `重绘资料.zip`；后者保存 SVG 和绘图 CSV。
- [模型与风险结果](report/模型与风险结果.md)、[评价对照](report/evaluation_comparison.csv)、[压力案例](report/heldout_stress_cases.csv)。
- `audit/`：原运行的核验结论与文件哈希。记录中的本机路径用于溯源；部分被核验的完整运行文件未随本精简包提供。

在依赖已安装的环境中，可于 `q2/代码` 执行 `python -X utf8 package_paper_results.py --html-only`，依据保存记录刷新 HTML 的文字分析。该命令不会重新优化购电计划。

## 重新运行

新电脑需准备题目原始附件并配置运行环境。请为新实验指定新目录，例如在 `q2/代码` 执行：

```powershell
python -X utf8 run.py run-all --workers 7 --attachments D:/题目附件 --output ../结果/statistical_risk_v2
```

Git 对冻结计算代码与论文结果保留原始字节，避免跨平台换行转换破坏已记录的 SHA256。实验摘要与论文取数应以同一轮冻结记录为准。
